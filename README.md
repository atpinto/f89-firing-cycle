# F89 Minimi Firing Cycle

Interactive three.js view of the F89 Minimi firing cycle: a photo-based exterior that can be made solid or see-through, over a simplified model of the open-bolt, belt-fed, gas-operated mechanism. Play, pause, slow down and scrub through twelve named phases.

**Live page:** https://atpinto.github.io/f89-firing-cycle/

Created by LT Armando Teixeira Pinto, 2HB D-COY 1 PL.

The internal parts are approximate and for illustration only. See `reference-photos/README.md` for how the exterior is built from the photo.
